## About

A single pickup line, at most 200 characters, spoken by a vending machine
flirting with a passing human. Version 2 takes a fresh angle from v1: no
coil, no B7, no falling — instead, every button on the machine lights up
when the human walks past, and the invitation to press one turns out to be
a pretext. The joke lands in the last few words, when the buttons confess
they're all just excuses to say hi: warm, cheeky, and only a machine
with lit buttons could say it. One breath, 104 characters, no setup
left unexplained.

## The entry

> "Every button I have lights up when you walk past — go on, press one, they're all just excuses to say hi."

## How it works

`main.ts` (Node 22, no dependencies) writes exactly that one line to
`entry.txt` inside the output directory:

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
